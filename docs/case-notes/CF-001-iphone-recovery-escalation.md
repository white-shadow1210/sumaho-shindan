# CF-001｜iPhone復旧画面から正規サービスへ接続

- **発生日**: 2026-09-22〜2026-09-23
- **起点**: FT-001 西浜スマホ相談会
- **相談方法**: SMS / 電話
- **種別**: アフター相談 / 端末トラブル
- **個人情報**: 匿名化済み
- **Status**: Resolved

## 1. 概要

相談会参加者の1名が、帰宅後にiPhoneをPCへ接続し、久しぶりのバックアップ・同期を試みた。

約2時間経過しても処理が進まないと感じ、途中でケーブルを外した。

その後、iPhoneが通常起動せず、PCとケーブルへの接続を求める復旧系の画面が表示された。

当日夜に家族の端末からSMS、翌朝に電話で再相談があった。

## 2. 相談時に把握できたこと

- iPhoneが通常操作できない
- PCとケーブルの接続を求める画面が出ている
- 直前にPC接続・同期/バックアップ作業を行っていた
- 処理途中と思われるタイミングでケーブルを外していた
- 本人はPC側のiTunes等が正常に入っているか確信がない
- 相談側もその場でPC環境を用意できない
- バックアップ状態・データ保全状況を電話だけでは十分確認できない

## 3. 実際の判断

遠隔でPC操作や復旧作業を続けるより、

- データ消失リスク
- PC環境の不確実性
- 本人の操作負荷
- 現物確認ができないこと

を考慮し、Apple正規サービスプロバイダへの相談を案内した。

## 4. 結果

正規サービスプロバイダで対応を受け、約30分で無事復旧。

本人からは、解決報告とともに今後も相談したい旨の返信があった。

## 5. 良かった点

- 無理に遠隔復旧を続けず、専門窓口へ接続した
- 「ショップに行けば何とかなる」という曖昧な案内ではなく、正規サービス系の窓口へ案内した
- 復旧後に結果確認ができた
- 相談会翌日に再相談が発生し、「困ったらまず相談する相手」として想起された

## 6. 改善点

今回、正規サービスへ接続する前に、

> **強制再起動など、安全性の高い基本操作を一度試す**

という段階を挟めた可能性がある。

そのため、今後は以下を基本順序とする。

1. 画面状態・直前操作・バックアップ状況を確認
2. データを消さない、安全な基本操作を優先
3. 改善しない場合のみ次の手段へ進む
4. データ消失や誤操作リスクが高い場合は、無理に遠隔対応しない
5. 専門窓口へ接続
6. 可能なら結果確認

## 7. 今回事例から得たサービス上の学び

街のスマホ相談士の価値は、

> **何でも自分で修理することではない。**

相談内容を整理し、

- 自分で解決できる
- 一緒に操作すれば解決できる
- 契約先へ行くべき
- メーカー・正規修理へ行くべき
- 専門店へ相談すべき

を判断して、適切な次の一手へつなぐことにも価値がある。

これは「スマホのかかりつけ医」というサービス定義と一致する。
