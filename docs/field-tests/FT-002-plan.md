# FT-002｜次回スマホ相談会 実証計画

- **実施日**: TBD
- **場所**: 西浜公会堂を第一候補
- **形式**: 無料・予約不要
- **時間**: FT-001と比較可能な時間帯を優先
- **種別**: 第2回地域実証
- **Status**: Planned

## 1. 目的

FT-001で確認できなかった「告知導線を追加した時に来場行動がどう変わるか」を検証する。

今回は、相談会そのものの内容を大きく変えるのではなく、**認知導線の違い**を主な変数として扱う。

## 2. Baseline

FT-001の基準値:

- 来場者数: 2名
- 大規模告知: なし
- ポスティング: なし
- 有料広告: なし
- Instagram / Threadsでの告知: あり
- 地域側の理解・継続意向: 前向き
- 実相談ニーズ: 複数確認
- 翌日再相談: 1件

## 3. FT-002で変える条件

### Primary Change
**地域内のオフライン告知を1つ追加する。**

第一候補:

- 町内ポスティング

代替候補:

- 町内会回覧
- 地域掲示板
- 公会堂掲示

### 変更しない条件

比較をしやすくするため、可能な限り以下は維持する。

- 無料
- 予約不要
- 同じ地域
- 同等の開催時間
- 「何でも聞いて大丈夫」という相談スタイル
- 売り込みを行わない
- 相談資料を準備する

## 4. 仮説

> オンライン告知だけでは届きにくい層に対して、地域内の紙ベースの告知を追加すると、相談会の存在を初めて知る人が増える。

また、

> 来場者数そのものだけでなく、「何を見て来たか」を記録することで、今後継続すべき認知導線を判断できる。

## 5. 今回の最重要計測

受付時に質問は増やしすぎない。

### 必須2問

1. **何を見て来ましたか？**
2. **今日、一番聞きたいことは何ですか？**

その他は運営側で匿名メモする。

## 6. 記録する項目

| 項目 | 記録方法 |
|---|---|
| 来場人数 | 合計 |
| 新規 / 再来 | 匿名区分 |
| 来場経路 | Instagram / Threads / チラシ / 回覧 / 紹介 / その他 |
| 主相談テーマ | カテゴリ化 |
| 相談時間 | おおよそ |
| 解決区分 | その場解決 / 継続 / 専門窓口接続 |
| 再相談 | 後日発生有無 |
| 次回参加意向 | 会話の中で自然に把握 |
| 運営メモ | 匿名 |

## 7. 相談テーマの分類案

後から比較しやすくするため、相談内容を以下へ分類する。

- 基本操作
- アカウント / パスワード
- 通知 / 設定
- Wi-Fi / 通信
- 容量 / バックアップ
- バッテリー
- 迷惑SMS / 詐欺
- 料金 / 契約
- 買い替え
- データ移行
- 故障 / 修理
- アプリ
- その他

## 8. 告知クリエイティブ方針

FT-001の反省から、告知は「イベント説明」だけでなく、**自分ごと化できる困りごと**を前面に出す。

例:

- 「LINEの通知が消えない」
- 「アカウントって何？」
- 「このSMS、本物？」
- 「機種変更したいけど何を選べばいい？」
- 「こんなこと聞いていいのかな？」

メインメッセージ:

> スマホの「ちょっと分からない」を、気軽に聞ける場所です。

補助メッセージ:

> 売らない・急かさない・どこにも属さない。

## 9. 当日の運営

### 開場前
- 会場写真を1枚
- 配布資料・机上の準備写真
- 受付メモ準備
- 相談カテゴリ一覧を確認

### 相談中
- 原則として相談者を撮影しない
- 必要な場合は明示的な許可を得る
- 相談内容は個人を特定しない形でメモ

### 終了後
- 来場人数
- 来場経路
- 相談カテゴリ
- 解決区分
- 印象的な気づき
- 次回改善点

を当日中に記録する。

## 10. 評価方法

FT-002は「何人来たら成功」と単純判定しない。

以下を比較する。

### A. 認知
- オフライン告知経由の来場があったか
- 「初めて知った」という反応があったか

### B. 相談
- FT-001と異なる相談テーマが出たか
- 相談者がどこで困っていたか

### C. 信頼
- 再相談が発生したか
- 次回参加や家族紹介につながったか

### D. 運営
- 一人で対応可能な相談件数・時間だったか
- 待ち時間が発生したか
- 資料が機能したか

## 11. 判断ルール

### オフライン告知経由が確認できた場合
→ 次回も継続し、配布範囲・媒体を調整する。

### オフライン告知経由が確認できない場合
→ 「紙が効かない」と即断せず、配布場所・メッセージ・配布量を見直す。

### 来場者は少ないが相談密度が高い場合
→ 人数だけで打ち切らず、継続価値を別軸で評価する。

### 来場者が増えて一人対応が難しくなった場合
→ 予約枠・時間制・受付整理の導入を検討する。

## 12. SNS連動

FT-002ではSNSを単なる告知ではなく、以下の3段階で使う。

1. **Before**
   - 困りごと起点の告知
2. **During**
   - 会場準備・開催中であることをStoriesで共有
3. **After**
   - 数字を隠さず活動記録として報告

個別相談事例は、本人が特定される可能性がある場合はリアルタイム投稿しない。
